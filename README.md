## O que o app faz

| Função | Descrição |
|---|---|
| Converter | Converte imagens entre PNG, JPG, JPEG, WEBP, BMP, GIF, TIFF, AVIF, ICO e SVG |
| Remover Fundo | Remove o fundo de qualquer imagem automaticamente com IA |

## Download

Baixe a versão mais recente na página de [Releases](https://github.com/brunoosz/teste/releases/latest).

| Arquivo | Para quê |
|---|---|
| `FileFlow-Setup-<versão>.exe` | Instalador para Windows 10 ou 11 |
| `FileFlow-Portatil-<versão>.exe` | Versão para Windows que roda sem instalar |

**Windows:** o app não tem certificado de assinatura digital, então o Windows pode mostrar "O Windows protegeu o computador". Clique em **Mais informações → Executar assim mesmo**.

Baixe os arquivos só pela página de Releases deste repositório.

## Feito com

React, TypeScript, Vite e Tailwind CSS na interface, Electron no Windows. Sharp para conversão de imagens e @imgly/background-removal-node para remoção de fundo.
